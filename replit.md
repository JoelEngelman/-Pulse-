# Pulse — Messaging App

A real-time messaging app where you can message anyone. Features emoji reactions, online presence, typing indicators, message search, and read receipts.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 8080)
- `pnpm --filter @workspace/chat-app run dev` — run the frontend (port 18228)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL`, `SESSION_SECRET`

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- Frontend: React + Vite, TanStack Query, wouter, Tailwind CSS, framer-motion
- API: Express 5 + express-session (connect-pg-simple session store)
- DB: PostgreSQL + Drizzle ORM
- Auth: Session-based with bcryptjs password hashing
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

- `lib/api-spec/openapi.yaml` — single source of truth for all API contracts
- `lib/db/src/schema/` — DB schema (users, conversations, messages, reactions, typing)
- `artifacts/api-server/src/routes/` — Express route handlers
- `artifacts/api-server/src/lib/` — auth middleware, user helpers
- `artifacts/chat-app/src/` — React frontend (pages/, hooks/, components/)

## Architecture decisions

- Session-based auth (not JWT) — simpler, fits the monorepo pattern
- Polling for real-time: conversations every 3s, messages every 2s, typing every 1s
- Unique constraints on `message_reactions(message_id, user_id, emoji)` and `typing_indicators(conversation_id, user_id)` for upsert ON CONFLICT
- `lib/api-zod/src/index.ts` only exports from `generated/api` (not `generated/types`) to avoid Orval param-type name collisions
- Orval config: removed `schemas: { path: "generated/types", type: "typescript" }` to prevent TS2308 collisions on query-param operations

## Gotchas

- After any OpenAPI spec change, run `pnpm --filter @workspace/api-spec run codegen` before editing routes or frontend
- `lib/api-zod/src/index.ts` is NOT regenerated by Orval — it's a hand-maintained barrel; keep it as `export * from "./generated/api"` only
- req.params values are `string | string[]` in Express 5 — always cast with `String(req.params["key"])` before parseInt/decodeURIComponent
